# KAI Engineering

This is my engineering workspace for learning, experimenting, building and documenting my progress toward Intelligent Systems Engineering.

My main direction is to understand how software, operating systems, networks, hardware, IoT, automation and AI work together to form real systems.

I am not trying to learn technologies as isolated topics. I want to understand how the parts connect and eventually use them to build intelligent systems.

## My learning method

LEARN → EXPERIMENT → OBSERVE → UNDERSTAND → DOCUMENT → VERIFY → BUILD → MOVE ON

For important work I keep evidence of what I actually tested. I do not claim something as completed if I only read about it.
